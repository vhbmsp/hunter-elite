# Hunter Elite

Fully web-based 3D hunter game built with Three.js.

## Quick start

1. Open `index.html` in a modern browser (Chrome/Edge/Firefox).
2. Click the page to lock the pointer.
3. Hold RMB for scope, click or Space to shoot.

## Controls
- Mouse look (pointer lock)
- RMB: scope zoom
- LMB or Space: shoot
- T: toggle hitbox debug
